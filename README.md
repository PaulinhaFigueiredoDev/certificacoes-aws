# Certificações AWS

Material de estudo para certificações AWS, com foco inicial na certificação
**AWS Certified AI Practitioner — AIF-C01**.

## Objetivo

Organizar resumos, conceitos fundamentais e materiais de apoio para facilitar a
preparação para as certificações AWS.

## Conteúdos

### AWS Certified AI Practitioner — AIF-C01

- Conceitos básicos de computação em nuvem
- Infraestrutura global da AWS
- Principais serviços da AWS
- Inteligência Artificial
- Machine Learning
- Deep Learning
- Desenvolvimento responsável de IA
