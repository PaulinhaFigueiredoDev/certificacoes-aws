# Computação em nuvem: Recursos de TI sob demanda (computação, armazenamento, bancos de dados) via Internet.

1. Benefícios: Eficiência de Custos, Escalabilidade, Alcance Global, Velocidade/Agilidade, Segurança.

## Infraestrutura global da AWS:

   1. Regiões: Data centers geográficos em todo o mundo.
   2. Zonas de disponibilidade (AZs): Vários data centers em cada região para redundância.
   3. Locais de borda: Caches locais que aceleram a entrega de conteúdo via Amazon CloudFront.

## Principais serviços da AWS:

   1. Computação: **Amazon EC2**: Servidores virtuais (instâncias) para diversas cargas de trabalho (incluindo IA/ML).
   2. Armazenamento: **Amazon S3:** Armazenamento de objetos (objetos em buckets) para grandes conjuntos de dados.
   3. Banco de dados: **Amazon RDS**: Bancos de dados relacionais (dados estruturados). **Serviço Amazon OpenSearch**: Para pesquisa semântica.
   4. Rede: **Amazon VPC**: Rede privada na AWS.
